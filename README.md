# Khi AI viết code

Bài thuyết trình của **Nhóm 05 – Kỹ năng thuyết trình lớp CT01**: *Cơ hội việc làm và năng lực cần có của sinh viên Công nghệ thông tin*.

Xem trực tiếp: https://tamnhd.github.io/khi-ai-viet-code/

## Điều khiển

| Phím | Chức năng |
|---|---|
| `→` / `Space` / `←` | Chuyển slide |
| `F` | Toàn màn hình |
| `O` | Tổng quan các slide |
| `N` | Ghi chú người nói |
| `P` | Cửa sổ người trình bày (ghi chú, slide kế, đồng hồ) |
| `?` | Bảng phím tắt |

Chạy offline: mở `index.html` bằng trình duyệt.
